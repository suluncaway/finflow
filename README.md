# finflow
FinFlow Pro; gelir, gider ve borç yönetimini tek ekranda toplayan web tabanlı bir finans panelidir. Çığ (Avalanche) metoduyla faiz yükünü düşürecek borç kapatma planı sunar; kredi kartı, KMH ve taksitleri takip eder. Excel entegrasyonu ve dinamik grafikleriyle bütçe kontrolü sağlar. Verileriniz sunucuya gitmeden tarayıcınızda güvenle çalışır.
